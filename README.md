# sparkeeeeey.github.io

Portfolio site for Yoobin Park. Vite + React + TypeScript + Tailwind CSS.

- `npm install` then `npm run dev` to work locally
- Content (projects, experience, skills) lives in `src/data.ts`
- Images and video live in `public/img/`
- Pushing to `main` builds the site and publishes it to the `gh-pages` branch (see `.github/workflows/deploy.yml`)
